# TriPeaks 游戏

一个基于 React + TypeScript + TailwindCSS 构建的 PC 端 TriPeaks 纸牌游戏，支持随机生成游戏、手动游玩和自动求解。

![TriPeaks Game](https://github.com/user-attachments/assets/ccbb352d-5873-4742-86b0-79ecdd6a144f)

## 功能特性

### 游戏模式

- **随机生成游戏** - 每次新游戏都会随机洗牌并发牌，创建独特的游戏局面
- **手动游玩** - 点击卡牌移动到弃牌堆，点击库存翻出新卡
- **自动求解** - 使用贪心算法自动求解当前游戏状态
- **继续求解** - 可以先手动玩几步，然后让程序继续求解
- **步骤回放** - 查看完整的求解步骤历史，点击任意步骤查看对应的棋盘状态

### 核心功能

- **游戏规则验证** - 自动检查卡牌是否可以移动（点数相差1或K-A循环）
- **卡牌遮挡检测** - 只有未被其他卡牌覆盖的卡牌才能移动
- **新游戏** - 重置游戏并生成新的随机牌局
- **重置** - 将当前游戏重置到初始状态
- **导入/导出** - 将游戏状态保存为 JSON 文件，或从文件导入

### 求解算法

- 使用贪心算法尝试从金字塔中移除卡牌
- 当金字塔无法移除时自动从库存翻牌
- 记录求解过程中的所有步骤
- 显示详细的步骤描述（包含卡牌花色和点数）

### 现代化 UI

- 使用 React + TypeScript + TailwindCSS 构建
- 响应式金字塔布局，正确显示卡牌遮挡关系
- 花色颜色编码（红色表示红桃/方块，黑色表示梅花/黑桃）
- 可移动的卡牌高亮显示绿色边框
- 被遮挡的卡牌显示为深色

## 技术栈

- React 18.2
- TypeScript 5.2
- TailwindCSS 3.3
- Vite 5.0 (构建工具)
- ESLint (代码质量)

```bash
npm install
```

### 开发模式


```bash
npm run build
```

## 使用说明

1. **开始游戏**：点击"新游戏"按钮生成随机牌局
2. **翻牌**：点击库存（蓝色方块）翻出一张新卡到弃牌堆
3. **移动卡牌**：点击未被覆盖的金字塔卡牌（白色卡牌）将其移动到弃牌堆
   - 只能移动点数与弃牌堆顶部卡牌相差1的卡牌
   - K 和 A 可以相邻（如：K-A-2 或 2-A-K）
4. **求解**：点击"求解"按钮查看当前局面的解法
5. **查看步骤**：在求解步骤历史中点击任意步骤，可以查看该步骤的棋盘状态
6. **继续游戏**：查看解法后点击"继续游戏"可以返回手动游玩
7. **重置**：点击"重置"按钮将游戏恢复到初始状态
8. **导出/导入**：点击"导出"保存当前游戏状态，点击"导入"加载之前保存的状态

## TriPeaks 规则

TriPeaks（三峰纸牌）是一种单人纸牌游戏：

### 游戏设置
- 28张卡牌排成三个金字塔形状（三峰）
  - 第0行：3张卡牌（峰顶）
  - 第1行：6张卡牌
  - 第2行：9张卡牌
  - 第3行：10张卡牌（底部）
- 24张卡牌作为库存
- 弃牌堆初始为空

### 游戏玩法
- **目标**：移除金字塔中的所有卡牌
- **移动规则**：
  - 只能移动未被其他卡牌覆盖的卡牌
  - 卡牌可以移动到弃牌堆，如果其点数与弃牌堆顶部卡牌相差1
  - 例如：弃牌堆是6，可以移动5或7
  - 允许"转角"：K-A-2-A-K（A可以放在2或K上）
- **翻牌**：当金字塔中没有可移动的卡牌时，可以从库存翻出一张卡到弃牌堆
- **库存**：只能翻一次，没有重置

### 胜负条件
- **获胜**：移除金字塔中的所有28张卡牌
- **失败**：金字塔中仍有卡牌，但库存已空且无法继续移动
